# Jenkins Home Insights Plugin

This task presents a restart-safe, read-only Jenkins analysis plugin over a deterministic controller-home export. The work covers canonical ingestion, full and incremental convergence, queue and build analysis, artifact lineage, plugin inventory, durable generation recovery, retention, authorization-safe projection, and equivalent CLI/HTTP output.

The separate verifier compiles the Java core and exercises generated homes, reconciliation, event replay, restart, corruption fallback, migration, compaction, authorization, deterministic queries, and Jenkins integration signatures. Oracle reward 1 and NOP reward 0 are required before packaging.
