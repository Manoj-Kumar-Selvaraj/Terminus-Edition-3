The payments platform still has Windows writers for a handful of private workloads. We need a credentialless Linux replacement plan and a local rehearsal that proves disks, checksums, and dependency waves before anyone touches prod DNS.

Inventory and evidence live under `/app/data` and `/app/evidence`. The transition contract is `/app/docs/wave-transition-contract.md`. Repair the Terraform under `/app/terraform`, then run `/app/bin/wave-rehearsal`. That command must regenerate the plan, materialize guests under `/app/var/wave`, restore snapshot payloads, and leave `/app/output/cutover-journal.json` plus `/app/output/rehearsal-report.json`. Writer/DNS handoff for a workload happens only after its dependency wave is healthy; a failed attach or health check must leave the Windows writer active and must not mount the same disk in two places. A second identical rehearsal must be a no-op on the report digest.
